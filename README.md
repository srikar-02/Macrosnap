# 🥗 MacroSnap

MacroSnap is an AI-powered nutrition chatbot built using **Python, Streamlit, and Google Gemini**.

## Features

- 💬 Ask questions about meals
- 📷 Upload a meal photo
- 🔢 Get estimated calories
- 🥩 Get protein, carbohydrates, and fat estimates
- 🤖 AI-powered meal analysis

## Technologies Used

- Python
- Streamlit
- Google Gemini API
- Twilio
